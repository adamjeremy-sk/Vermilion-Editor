- **M2.4 design, in one paragraph (details in the archive, Part 28):** a clean tab whose file changes reloads silently (undo cleared, cursor and scroll kept, status line says so); an edited tab gets a banner (Reload, Keep mine; Keep mine takes the disk's time, size and hash as the baseline); our own saves are told from outside changes by time and size, then an xxHash of the bytes (vendored, `third_party/xxhash`); a deleted or moved file keeps its tab and text, is marked as needing a save, and gets a recovery copy; only the active tab is watched (300 ms debounce), background tabs are checked on switch, every tab at quit; above 10 MiB a clean tab gets the banner (Reload, Ignore); a chosen encoding survives reloads; File > Reload from Disk is Ctrl+R; the one setting is `[files] confirm-large-reload` (renamed `confirm_large_reload` at M2.5 step 1) in `$XDG_CONFIG_HOME/vermilion/settings.ini` (default true); a damaged settings file falls back to defaults and is moved to `settings.ini.bad` on the next change; whether a reload keeps the old text for Show diff is for the M2.6 talk.
- **M2.5 design (Adam, 2026-11-19; full list in the archive, Part 35):** a modal Settings window with the tabs Appearance, Editor, Files, opened from a Tools menu (both programs) and Ctrl+Comma; controls rule: check box (on or off), drop-down (one of a fixed set), number box, font button, text box, no radio buttons, no switches; colour mode Light, Dark or Follow system, the editor colours follow it; the Tab key inserts spaces, width 4 or 8; changes take effect at Apply, debounced 100 ms, no restart, no preview; the dark palette (from Greybird-dark's colours) is built in the same gate first; settings keys use underscores; Light and Dark can always be chosen by hand.
- **M2.4b design (Adam, 2026-11-19):** `vermilion file...` opens every file; a missing file asks on the terminal `(Y/n)` and on yes is created and opened; a folder is refused ("XXX is a directory, not a file"); `file:line` left out; the command line closes the untouched blank document, File > Open does not; built on `HANDLES_COMMAND_LINE` (the terminal belongs to the launching process), which means GApplication parses no options, so `--help` and `-h` are answered in `main.cpp` (a file named like one is written `./--help`).
