# Using the manual
The manual opens from Help → Index, or with F1. It has one short page for each topic, and it opens on the list of
topics.

## Moving around
- Click a link to open another page. The new page replaces the one you were reading.
- **Back**, or Alt+Left, returns to the page you came from. It is greyed out on the first page.
- **Index** returns to the list of topics.
- Scroll with the mouse wheel or the scroll bar. Every page starts at the top.

## The window
The manual has its own window, and there is only one: choosing Help → Index again brings the open window forward. The
editor stays usable while the manual is open. Close the manual with its close button; it also closes when the editor
closes.
