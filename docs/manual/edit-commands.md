# Edit commands
The Edit menu works on the active document, also while the menu is open.

| Command | Shortcut | What it does |
|---|---|---|
| Undo | Ctrl+Z | Takes back the last change. |
| Redo | Ctrl+Y or Ctrl+Shift+Z | Makes an undone change again. |
| Cut | Ctrl+X | Moves the selected text to the clipboard. |
| Copy | Ctrl+C | Copies the selected text to the clipboard. |
| Paste | Ctrl+V | Inserts the clipboard's text at the cursor. |
| Select All | Ctrl+A | Selects the whole document. |

Undoing back to the last unchanged state removes the `*` from the tab.
