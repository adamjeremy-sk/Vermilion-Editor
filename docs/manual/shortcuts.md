# Keyboard and mouse shortcuts

## Keyboard
| Keys | Command |
|---|---|
| Ctrl+N | New File |
| Ctrl+O | Open… |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As… |
| Ctrl+R | Reload from Disk |
| Ctrl+W | Close Tab |
| Ctrl+Q | Quit |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+X | Cut |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+A | Select All |
| Ctrl+F | Find… |
| F3 | Find Next |
| Shift+F3 | Find Previous |
| Ctrl+H | Replace… |
| Ctrl+G | Go to Line… |
| Ctrl+Page Down | Next tab (after the last tab comes the first) |
| Ctrl+Page Up | Previous tab (before the first tab comes the last) |
| Ctrl+Comma | Tools → Settings… |
| Insert | Switch between inserting (INS) and overwriting (OVR) |
| Alt | Show the access letters in the menu bar |
| Escape | In a question or in the Settings window: Cancel |
| F1 | Help → Index: open the manual, or bring it forward |
| Alt+Left | In the manual window: Back to the previous page |
| Alt+Right | In the manual window: Forward to the page that Back left |
| Ctrl+F, F3, Shift+F3 | In the manual window: search the manual, next and previous match on the page |
| Ctrl+=, Ctrl+-, Ctrl+0 | In the manual window: larger text, smaller text, normal size |

The editor's own keys (arrows, Home, End, Page Up, Page Down, Ctrl+Home, Ctrl+End, and Shift with any of them to select)
work as in other GTK text editors.

## Mouse
- Middle click on a tab: close it.
- Mouse wheel over the tabs: next or previous tab (it stops at the first and the last).
- Drag a tab: move it.
