# Keyboard and mouse shortcuts

## Keyboard
| Keys | Command |
|---|---|
| Ctrl+N | New File |
| Ctrl+W | Close Tab |
| Ctrl+Q | Quit |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+X | Cut |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+A | Select All |
| Ctrl+Page Down | Next tab (after the last tab comes the first) |
| Ctrl+Page Up | Previous tab (before the first tab comes the last) |
| Insert | Switch between inserting (INS) and overwriting (OVR) |
| Alt | Show the access letters in the menu bar |
| Escape | In a question: Cancel |

The editor's own keys (arrows, Home, End, Page Up, Page Down, Ctrl+Home, Ctrl+End, and Shift with any of them to select)
work as in other GTK text editors.

## Mouse
- Middle click on a tab: close it.
- Mouse wheel over the tabs: next or previous tab (it stops at the first and the last).
- Drag a tab: move it.
